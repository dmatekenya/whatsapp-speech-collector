# Public website and supervision dashboard

The public ZaZoAI Projects site (`zazoai.com/projects.php`) and the authenticated Masakhane supervision application (`masakhane.zazoai.com`) are separately deployed applications. The public status-card removal belongs to the ZaZoAI website package, not to this dashboard repository.

The dashboard uses the grouped public demographic feed through an authenticated proxy. Do not place website CMS content, private publisher credentials or direct DigitalOcean database access in the dashboard repository.
