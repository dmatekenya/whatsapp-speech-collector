## Write-back (`gateway/writeback.py`)

1. **Add `no_speech` to `REJECTION_REASONS`.** The final list is `wrong_sentence`, `no_speech`,
   `noise`, `unclear`, `not_own_voice`, `not_chichewa`, `other`. The database also enforces a
   500-character limit on notes, and requires a note for `other`.
2. **Map database errors to the right responses.** At the moment every database error becomes 503
   "retry with same operation key", which can never succeed in these cases:
   - **SQLSTATE `QC409`** (another supervisor changed the clip's tier-3 state first) → 409 "Tier 3
     state changed; refresh before submitting".
   - **SQLSTATE `QC405`** (attempt to change or delete a review) and **`23514`** (a database rule
     broken, e.g. `other` without a note) → 422.
   - Keep 503 "retry" only for connection errors and timeouts.

## Sync (`gateway/gateway.py`)

3. **Don't miss late commits in `/changes`.** `updated_at` is stamped when a transaction *starts*,
   so a row committed a moment after your `until = now` can carry an earlier timestamp and fall
   behind the cursor for good. Please use `until = now() - 2 minutes`, or overlap each sync by two
   minutes. The overlap is safe because you upsert by recording id.
4. **Make "collected minutes" in `/summary` match what contributors see.** The bot counts only the
   current clip of each answered prompt that isn't rejected or a duplicate (`minutes_recorded()` in
   [src/tasks/bank.py](https://github.com/dmatekenya/whatsapp-speech-collector/blob/main/src/tasks/bank.py)). Your query currently also counts clips sent
   outside a session and earlier takes of a prompt. For project totals, also leave out test
   participants. The equivalent query (drop `AND NOT p.is_test` and group by participant for one
   contributor's progress):

   ```sql
   SELECT a.prompt_type, SUM(r.duration_s)
   FROM assignments a JOIN recordings r ON r.id = a.recording_id
   JOIN participants_public p ON p.participant_id = r.participant_id
   WHERE a.status IN ('recorded', 'accepted') AND r.status = 'stored'
     AND r.qc_status <> 'rejected' AND r.duplicate_of_recording_id IS NULL
     AND NOT p.is_test
   GROUP BY a.prompt_type;
   ```

   Please exclude test participants from usable minutes (`qc_final` in `gold` or `silver`) too.
