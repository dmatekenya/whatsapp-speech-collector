# Supervision Dashboard — source update

Date: 12 November 2026  
Component: Masakhane Supervision Dashboard (Hostinger PHP application)

## Application source included

- Authenticated Overview with recording progress by sentence, picture, free speech and conversation-starter tasks.
- Quality-verified duration tracking and 500-hour usable-audio target.
- Contributor Demographics on the **admin** Overview, using aggregate Gender, Country, Age Group and First Language data from the existing ZaZoAI publication feed.
- Standardized five-year age groups, including exact ages and age ranges from participant metadata (aggregation remains on the publishing side).
- Supervisor assignment boundaries, recording search, playback, Accept/Reject decisions, action logs and reporting retained from the dashboard source tree.
- Human-review rejection reason `no_speech` is included alongside `wrong_sentence`, `noise`, `unclear`, `not_own_voice`, `not_chichewa`, `other`; notes remain limited to 500 characters, with explanation required for `other`.
- Dashboard source, admin-facing aggregate proxy and frontend assets are versioned; credentials, contributor records, avatars, recordings and runtime configuration are excluded.

## Production collector compatibility

The collector maintainer's 11 November 2026 deployment note reports Alembic head `e2a6c4f8b913`, `qc_human_reviews` and new QC columns (`qc_tier2`, `qc_tier3`, `qc_tier3_reason`, `qc_final`). It reports that `qc_status` transitions to `accepted`, `needs_review` or `rejected`, with `pending` transient, and that duplicate clips are rejected.

The following collector/gateway work is described in that note and **is not delivered by this PHP dashboard source archive**:

- In `gateway/writeback.py`, accept `no_speech`, map SQLSTATE `QC409` to HTTP 409 and `QC405` / `23514` to HTTP 422; reserve 503 retry semantics for transport/timeout errors.
- In `gateway/gateway.py`, overlap `/changes` synchronization by two minutes (or move `until` two minutes behind current time) to avoid dropping late-committing rows. Record upserts must remain idempotent.
- Align `/summary` collected minutes with current, non-rejected, nonduplicate assigned prompts; exclude test participants from project-wide recorded and gold/silver usable totals.
- In the collector repository, update `operator_scripts/read_only_preflight.sh` for Alembic `e2a6c4f8b913`, and check `/changes` and `/summary` in `check_gateway_contract.py`.

Those changes require review, implementation and testing in the DigitalOcean collector repository, not this PHP application.

## Data access and review authorization

- Admin users have project-wide visibility; supervisor pages remain scoped to their assignments.
- Demographic plots use only grouped duration data, combining small groups to reduce disclosure risk.
- Official QC write-back must remain owner-controlled; the gateway's dedicated writer credential is not bundled here.
- End-to-end activation depends on the production owner's approval and write-status validation.

## Scope and source status

This package is a consolidated, secret-free PHP dashboard source tree based on the available dashboard archive. It is **not a verified byte-for-byte export of the live Hostinger deployment**. Changes made directly on Hostinger after the original archive must be reconciled before using the GitHub branch as the deployable production source.
