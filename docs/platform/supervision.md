# Supervision

The supervision dashboard supports clip review and records supervisor
decisions. The [dashboard plan](plans/supervision-dashboard-plan.md) describes
its workflow, and the [QC contract](plans/supervision-qc-contract.md) describes
how it writes tier-3 decisions. The [study contract](supervision-study-contract.md)
covers calibration clip checks. See the [dashboard updates](dashboard/updates-2026-11-11.md)
for changes made after the original plan.
