# Prompt generation references

## Primary project guide

- ZaZo AI Ltd. (2026). *Chichewa Speech Project: Prompt Generation and Review Manual*. Supplied as `prompt-generation-guide-v2.pdf` (14 pages). Primary source for the [methodology](methodology.md), [targets](targets.md), [annotator manual](manual.md) and [quality assurance](quality-assurance.md). No shared source URL was supplied; the PDF is not stored in this repository.

## Guides and collection protocols

- [Krewer, J. (2023). Creating community-driven datasets: Insights from Mozilla Common Voice activities in East Africa. GIZ.](https://assets.mofoprod.net/network/documents/Creating-Community-Driven-Datasets-Report-032023-GIZ-Mozilla.pdf) See printed pages 16–17 for sentence preparation and verification.

- [Mozilla Common Voice. (n.d.). Community Playbook: Text Corpus.](https://common-voice.github.io/community-playbook/sub_pages/text.html) Practical guidance on assembling and reviewing sentence prompts.

- [Wiafe, I., et al. (2025). Advancing automatic speech recognition for low-resource Ghanaian languages: Audio datasets for Akan, Ewe, Dagbani, Dagaare, and Ikposo. Data in Brief, 61, 111880.](https://pmc.ncbi.nlm.nih.gov/articles/PMC12301755/) See Section 4.1 for image selection and prompt categories.

- [Waxal-Multilingual. (n.d.). Waxal in a box: Speech-data collection package.](https://github.com/Waxal-Multilingual/speech-data/blob/main/collection/README.md) Documentation for a WhatsApp/Twilio collection pipeline using image, text and audio prompts.

- [Waraka Community. (n.d.). AfriPlaybook: Automatic Speech Recognition (ASR).](https://afriplaybook.waraka.org/asr) A Masakhane-supported guide to African-language ASR data collection and annotation.

## Domain and methodology references

- [IARPA. (2013). Babel Data Specifications for Performers.](https://www.nist.gov/system/files/documents/itl/iad/mig/IARPA_Babel_Performer-Specification-08262013.pdf) Section 3.3 lists broad conversational domains.

- [Cornell ConvoKit. (n.d.). Switchboard Dialog Act Corpus.](https://www.convokit.cornell.edu/documentation/switchboard.html) Documentation and examples of everyday discussion topics.

- [Google Research. (2026). WAXAL: A large-scale open resource for African language speech technology.](https://research.google/blog/waxal-a-large-scale-open-resource-for-african-language-speech-technology/) Describes image-prompted ASR collection with African academic and community partners.

- [Gauthier, E., Ndiaye, A., & Guissé, A. (2024). Kallaama: A Transcribed Speech Dataset about Agriculture in the Three Most Widely Spoken Languages in Senegal. Proceedings of RAIL 2024, 10–19.](https://aclanthology.org/2024.rail-1.2/) An example of domain-focused agricultural speech collection.
