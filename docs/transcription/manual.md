# Transcription manual

**Status: stub — approved human transcription instructions are not yet available.**

The existing automatic process produces raw Chichewa ASR transcripts. It does not establish an approved human annotation convention.

Required before human annotation starts: spelling and punctuation conventions; dialect and code-switching rules; treatment of numbers, disfluencies, unintelligible speech and background speakers; segmentation; annotation tooling; reviewer responsibilities; adjudication; and release sign-off.

See {doc}`/transcription/methodology` for implemented ASR behavior and {doc}`/transcription/quality-assurance` for automatic checks.
