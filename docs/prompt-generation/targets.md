# Prompt targets

Current prompt coverage limits are configured in `config/assignment_settings.yaml`:

| Type | Different speakers per prompt |
| --- | --- |
| Sentence | 5 |
| Image | 7 |
| Conversation starter | 3 |
| Free speech | No prompt bank |

These are coverage limits, not a total prompt-production quota. Pending assignments also reserve capacity. Prompts carry over across rounds.

Run the task-bank simulation before each collection run. An earlier pilot simulation exhausted 24 images at five speakers each; the design moved to about 50 images with seven speakers each.
